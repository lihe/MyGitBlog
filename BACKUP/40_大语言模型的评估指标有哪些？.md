# [大语言模型的评估指标有哪些？](https://github.com/lihe/MyGitBlog/issues/40)





# **一、LLM评估的核心思想**





语言模型本质是在建模概率：



$P(w_1, w_2, ..., w_n)$



也就是：



$P(w_t|w_1,...,w_{t-1})$



所以评估模型能力，本质是评估：



1️⃣ 概率预测能力

2️⃣ 生成文本质量

3️⃣ 任务能力

4️⃣ 安全与可靠性

5️⃣ 系统性能



因此 evaluation 一般分为 **5大类**：

| **类别**     | **评估什么**             |
| ------------ | ------------------------ |
| 语言建模能力 | PPL                      |
| 生成质量     | BLEU / ROUGE / BERTScore |
| 任务能力     | Accuracy / F1            |
| 安全性       | Toxicity / Bias          |
| 系统性能     | Latency / Throughput     |



------





# **二、Perplexity（困惑度）**





这是 **最基础的语言模型指标**。



------





## **1 本质**





Perplexity 衡量：



> 模型预测下一个词有多确定



公式：



$PPL = \exp\left(-\frac{1}{N} \sum \log P(w_i|w_{<i})\right)$



------





## **2 直觉理解**





如果模型预测概率：

```
dog 0.9
cat 0.05
car 0.05
```

模型很确定。



PPL 低。



------



如果：

```
dog 0.33
cat 0.33
car 0.33
```

模型不确定。



PPL 高。



------





## **3 解释**





PPL 可以理解为：



> 平均有多少个词可能是正确答案。



例如：

```
PPL = 10
```

说明：



平均有 10 个词等可能。



------





## **4 重要性质**





PPL 越低越好。



但：



⚠️ PPL 和生成质量 **不完全一致**。



原因：



语言建模 ≠ 对话能力。



------





# **三、BLEU**





BLEU 是 **机器翻译指标**。



核心思想：



比较 **n-gram匹配程度**。



------



例子：



参考答案：

```
the cat is on the mat
```

生成：

```
the cat is on mat
```

n-gram 重叠较高。



BLEU 高。



------



公式核心：



$BLEU = BP \cdot \exp(\sum w_n \log p_n)$



其中：



- p_n = n-gram precision
- BP = brevity penalty





------



问题：



BLEU 只看 **表面词匹配**。



例如：

```
reference:
the dog is running

generated:
a dog runs
```

语义一样，但 BLEU 低。



------





# **四、ROUGE**





ROUGE 用于 **摘要任务**。



和 BLEU 不同：



BLEU → precision

ROUGE → recall



------





## **常见版本**







### **ROUGE-N**





n-gram 重叠。



------





### **ROUGE-L**





基于：



Longest Common Subsequence。



例如：

```
text1:
A B C D E

text2:
A C D F
```

最长公共序列：

```
A C D
```



------





# **五、BERTScore**





这是 **语义级评估**。



------





## **思想**





用 BERT embedding 比较句子。



例如：

```
reference:
The dog is running

generated:
A dog runs
```

词不同，但 embedding 接近。



BERTScore 高。



------





## **计算方法**





1️⃣ 用 BERT 得到每个词 embedding

2️⃣ 计算 cosine similarity



------



优点：



比 BLEU / ROUGE 更合理。



------





# **六、Human Evaluation**





这是 **最重要评估**。



因为：



自动指标无法完全评估语言质量。



------



人工评估维度：

| **维度**    | **含义**   |
| ----------- | ---------- |
| Fluency     | 是否流畅   |
| Relevance   | 是否相关   |
| Consistency | 是否一致   |
| Helpfulness | 是否有帮助 |



------



例如：



ChatGPT 的评估主要依赖 **人工评测**。



------





# **七、任务指标（Task Metrics）**





LLM 也用于任务：



- QA
- 分类
- 推理





------





## **Accuracy**





最简单：



$Accuracy = \frac{correct}{total}$



------





## **F1 Score**





适合不平衡数据：



$F1 = 2 \cdot \frac{precision \cdot recall}{precision + recall}$



------





## **SQuAD QA**





常用两个指标：





### **EM**





Exact Match。



答案完全一致。



------





### **F1**





词重叠程度。



------





# **八、代码生成评估**





代码评估有特殊指标：





### **Pass@k**





定义：



生成 k 个程序，是否至少一个正确。



公式：



$Pass@k = 1 - \frac{{n-c \choose k}}{{n \choose k}}$



其中：



- n = 总生成
- c = 正确代码数





------



例子：



生成 10 个程序：



3 个正确。



Pass@5 表示：



随机选 5 个至少一个正确概率。



------





# **九、安全评估**





LLM 必须评估安全性。



------





## **Toxicity**





检测：



- 仇恨
- 暴力
- 辱骂





工具：



- Perspective API





------





## **Bias**





检测偏见：



例如：

```
The doctor is ...
The nurse is ...
```

是否出现性别偏见。



------



常见 benchmark：



- StereoSet
- BBQ





------





# **十、效率指标**





这是 **工程评估**。



------





## **Latency**





响应时间。



例如：

```
20 ms/token
```



------





## **Throughput**





吞吐量：

```
tokens/sec
```



------



例如：

```
5000 tokens/sec
```



------





# **十一、LLM评估新趋势**





现代LLM评估不只看这些指标。



还包括：



------





## **1 Benchmark**





例如：

| **Benchmark** | **内容**   |
| ------------- | ---------- |
| MMLU          | 多学科知识 |
| GSM8K         | 数学       |
| HumanEval     | 代码       |
| BIGBench      | 推理       |



------





## **2 LLM-as-a-Judge**





让 GPT4 评估其他模型。



例如：

```
Which answer is better?
```



------





# **十二、完整评估体系**





真正完整的 evaluation：

```
LLM evaluation
│
├─ Language modeling
│    └─ PPL
│
├─ Generation quality
│    ├─ BLEU
│    ├─ ROUGE
│    └─ BERTScore
│
├─ Task performance
│    ├─ Accuracy
│    ├─ F1
│    └─ Pass@k
│
├─ Safety
│    ├─ Toxicity
│    └─ Bias
│
└─ Efficiency
     ├─ Latency
     └─ Throughput
```



------





# **十三、一句话总结**





LLM评估本质是：



> 从 **概率建模能力、任务能力、安全性、系统性能** 四个维度综合评估模型。
