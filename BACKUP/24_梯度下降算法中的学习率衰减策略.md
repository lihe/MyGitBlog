# [梯度下降算法中的学习率衰减策略](https://github.com/lihe/MyGitBlog/issues/24)





# **一、为什么必须做学习率衰减？**





先回答核心问题：



> 为什么不能一直用固定学习率？



因为梯度下降的两个阶段：





### **1️⃣ 初期**





- 离最优点远
- 梯度大
- 需要大步快走







### **2️⃣ 后期**





- 接近极小值
- 梯度小
- 需要小步精调





如果一直大 lr：



- 在最优点附近震荡
- 无法收敛





如果一直小 lr：



- 训练极慢





所以：



> 学习率本质是“步长调度器”



------





# **二、从优化理论看学习率衰减**





在随机梯度下降（SGD）理论中：



收敛需要满足：



$\sum \eta_t = \infty$

$\sum \eta_t^2 < \infty$



这意味着：



- 学习率不能衰减太快
- 但必须逐渐变小





典型满足条件的：



$\eta_t = \frac{1}{t}$



这就是逆时间衰减的理论来源。



------





# **三、各种衰减策略的本质区别**





我们按“曲线形状”理解。



------





## **1️⃣ 分段常数（Step decay）**





像楼梯一样下降。



特点：



- 简单
- 工程好调
- 容易突然改变优化轨迹





------





## **2️⃣ 指数衰减**





$\eta_t = \eta_0 \gamma^t$



优点：



- 平滑
- 早期下降快





缺点：



- 后期衰减太快
- 容易过早停止学习





------





## **3️⃣ 线性衰减**





$\eta_t = \eta_0 (1 - t/T)$



特点：



- 最简单
- 在 Transformer 预训练中非常常见





------





## **4️⃣ 余弦衰减（目前最常用）**





$\eta_t = \eta_{min} + \frac{1}{2}(\eta_{max}-\eta_{min})(1+\cos(\pi t/T))$



优点：



- 前期下降慢
- 中期下降快
- 后期平滑接近0





关键点：



> 余弦在后期非常平滑，不会突然变小。



这有利于稳定收敛。



------





## **5️⃣ 逆时间衰减**





$\eta_t = \frac{\eta_0}{1+\gamma t}$



理论最干净，但工程不常用。



------





# **四、Warmup 为什么必须？**





在 Transformer 中：



没有 warmup 会爆炸。



原因：



1. LayerNorm + Residual 结构
2. 初始化不稳定
3. Adam 的动量统计还未稳定





Warmup 的作用：



> 让梯度统计先稳定，再进入正常训练。



典型做法：



前 1%~10% steps 线性升到最大 lr。



------





# **五、为什么大模型几乎都用 Warmup + 余弦？**





因为：





### **1️⃣ 训练极长（百万步）**







### **2️⃣ 高维非凸优化**







### **3️⃣ 大 batch 训练**





余弦衰减的优点：



- 后期非常平滑
- 有利于找到更平坦的最优点





平坦极小值 → 泛化更好。



------





# **六、从损失曲面角度理解**





假设损失函数是：



一个高维山谷。



大 lr：



- 能快速越过鞍点
- 可能跳过最优





小 lr：



- 能精细下降
- 容易卡在局部极小





衰减本质是：



> 从探索 → 到收敛



------





# **七、大模型中特殊技巧**





------





## **1️⃣ Layer-wise LR**





浅层用小 lr

深层用大 lr



原因：



- 浅层接近通用表示
- 深层更 task-specific





------





## **2️⃣ 学习率重启（SGDR）**





余弦退火 + 周期重启



优点：



- 跳出局部极小
- 提高泛化





------





## **3️⃣ 不同参数不同 lr**





例如：



- bias 不衰减
- LayerNorm 不衰减
- embedding 单独设置





------





# **八、Adam 下的学习率意义**





注意：



Adam 中真实更新是：



$\Delta w = \eta \frac{m_t}{\sqrt{v_t}}$



学习率只是全局缩放因子。



所以：



Adam 的 lr 通常小于 SGD。



------





# **九、理论层面更深的理解**





最近研究发现：



大模型训练其实经历两个阶段：





### **Phase 1: 特征学习阶段**





大 lr 更重要





### **Phase 2: 细节对齐阶段**





小 lr 更重要



衰减调度帮助完成这两个阶段。



------





# **十、一个很关键的现象**





大模型训练后期：



loss 下降极慢。



这时：



学习率衰减太快会：



- 停止学习
- 提前收敛





余弦衰减的平滑尾部：



可以继续微调权重。



------





# **十一、为什么不直接用自适应优化器代替衰减？**





因为：



Adam 调节的是“维度方向的缩放”，

学习率调节的是“全局步长”。



两者不是一回事。



------





# **十二、一个直观总结图（脑中想象）**





学习率曲线应该：

```
    /
   /
  /    ← warmup
 /____
       \
        \
         \____ ← cosine
```



------





# **十三、面试级总结答案**





学习率衰减的核心作用是：



1. 初期快速收敛
2. 后期精细优化
3. 满足随机优化收敛条件
4. 帮助模型找到平坦极小值





常见策略包括：



- 分段衰减
- 指数衰减
- 线性衰减
- 余弦衰减（大模型常用）





并常结合 warmup 使用。
