# [L2 正则化为什么不容易让参数变成 0？](https://github.com/lihe/MyGitBlog/issues/28)





# **一句话结论（面试先说）**





> L2 正则化不会把参数压成 0，是因为它对参数的惩罚是连续且与参数大小成正比的，当参数接近 0 时梯度也趋近于 0，因此不会产生“强制归零”的效果。



------





# **一、从梯度角度看（最核心）**





L2 正则项：



$R(w)=\frac{\lambda}{2} w^2$



对 w 求导：



$\frac{\partial R}{\partial w}=\lambda w$



更新公式：



$w \leftarrow w - \eta(\nabla L + \lambda w)$



关键点：



👉 当 $w \to 0$ 时：



$\lambda w \to 0$



也就是说：



> 越接近 0，拉回 0 的力量越小



所以它只会：



- 把权重变小
- 但不会“硬压到 0”





------





# **二、对比 L1 为什么会变 0**





L1 正则项：



$R(w)=\lambda |w|$



导数：



$\frac{d}{dw}|w| = \begin{cases} +1 & w>0 \\ -1 & w<0 \end{cases}$



注意：



- 梯度是常数
- 不会随着 w 变小而变小





即便：



$w \to 0$



惩罚力度依然是：



$\pm \lambda$



所以：



> 会把小权重直接压到 0



这叫“稀疏性”



------





# **三、几何解释（非常重要）**





假设二维参数空间：



最小化：



$Loss + \lambda \|w\|^2$



约束区域：



- L2 是“圆形”
- L1 是“菱形”





圆形边界是光滑的：



- 最优点一般在非坐标轴上
- 不会卡在轴上





菱形有尖角：



- 尖角正好在坐标轴
- 容易产生 0





------





# **四、优化动态角度（直观理解）**





L2 更新：



$w \leftarrow (1-\eta\lambda)w$



这只是：



> 每步缩小一个比例



比如：



- w=0.1
- 每次乘 0.9





会变成：



0.1 → 0.09 → 0.081 → 0.0729 …



永远趋近于 0，但不会直接等于 0。



这叫：



> 指数衰减



------





# **五、再从概率角度理解**





L2 等价于：



$w \sim \mathcal{N}(0,\sigma^2)$



高斯先验：



- 鼓励小值
- 但不鼓励稀疏





而 L1 等价于：



$w \sim Laplace$



Laplace 分布在 0 点有尖峰：



- 强烈鼓励为 0





------





# **六、总结对比**



| **正则** | **梯度行为** | **是否变 0** |
| -------- | ------------ | ------------ |
| L2       | 与 w 成正比  | 不会         |
| L1       | 常数         | 会           |



------





# **七、面试标准总结（建议背）**





> L2 正则化的梯度与参数大小成正比，当参数接近 0 时惩罚力度也趋近于 0，因此只会使参数变小而不会压缩为 0；相比之下，L1 正则的梯度是常数，因此更容易产生稀疏解。



------





# **八、一句更高级的总结**





> L2 是“平滑收缩”，L1 是“硬阈值压缩”。



------
