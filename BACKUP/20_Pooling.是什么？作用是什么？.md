# [Pooling 是什么？作用是什么？](https://github.com/lihe/MyGitBlog/issues/20)





# **一、Pooling 是什么？**





**Pooling（池化）** 是 CNN 中的一种 **下采样操作**。



它的作用是：



> 把特征图“压缩变小”，同时保留最重要的信息。



------





# **二、最直观理解**





假设我们有一个 4×4 的特征图：

```
1 2 3 0
4 6 1 2
3 2 1 0
1 2 3 4
```

做 2×2 的 Max Pooling（步长2）：



每 2×2 区域取一个值。



第一块：

```
1 2
4 6
```

最大值 = 6



第二块：

```
3 0
1 2
```

最大值 = 3



最终变成：

```
6 3
3 4
```

原来 4×4 → 变成 2×2。



这就是 Pooling。



------





# **三、常见两种 Pooling**







## **1️⃣ Max Pooling（最常用）**





取区域内最大值。



优点：



- 保留最强特征
- 抗噪声
- 更鲁棒





------





## **2️⃣ Average Pooling**





取区域内平均值。



优点：



- 更平滑
- 保留整体信息





------





# **四、Pooling 的作用**







## **1️⃣ 压缩特征图（降维）**





尺寸变小 → 计算量减少 → 训练更快。



------





## **2️⃣ 增强平移不变性**





物体稍微移动：



Max Pooling 结果几乎不变。



例如：



一个亮点稍微移动，最大值仍然被保留。



------





## **3️⃣ 增大感受野**





Pooling 之后：



后面卷积层“看到”的原图范围更大。



------





# **五、Pooling 的本质**





Pooling 本质是：



> 在做“信息压缩”



卷积负责：



> 提取特征



Pooling 负责：



> 筛选重要信息 + 丢弃细节



------





# **六、一句话总结**





> Pooling = 局部区域压缩 + 保留主要特征



------





# **七、一个更深的理解（加分点）**





卷积是“平移等变”：



输入移动 → 输出也移动



Pooling 带来“平移不变性”：



输入小移动 → 输出基本不变



------





# **八、面试标准回答**





Pooling 是 CNN 中的一种下采样操作，通常通过 Max 或 Average 方式对局部区域进行聚合，从而减小特征图尺寸，降低计算量，同时增强平移不变性并扩大感受野。
