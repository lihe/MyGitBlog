# [比较GPT、BERT和T5的架构差异](https://github.com/lihe/MyGitBlog/issues/33)

从 6 个维度对比：



1. 架构结构
2. 注意力机制
3. 训练目标
4. 信息流方向
5. 适用任务
6. 为什么 GPT 赢了





------





# **一、从架构结构理解三者**





------





## **🔹 GPT：Decoder-only**





结构：

```
输入 → Masked Self-Attention → FFN → 输出
```

特点：



- 只有 Transformer Decoder
- 每层都有因果 mask
- 只能看左侧上下文





公式形式：



$P(x) = \prod_t P(x_t | x_{<t})$



这是标准语言建模。



------





## **🔹 BERT：Encoder-only**





结构：

```
输入 → Full Self-Attention → FFN → 输出表示
```

特点：



- 无 mask
- 每个 token 可以看到左右
- 不是生成模型





它是一个“表示学习器”。



------





## **🔹 T5：Encoder-Decoder**





结构：

```
Encoder(全注意力)
        ↓
Decoder(因果注意力 + 交叉注意力)
```

Decoder 还会：



- 对 Encoder 输出做 Cross-Attention





------





# **二、注意力机制本质区别**



| **模型** | **是否双向**             | **是否自回归** |
| -------- | ------------------------ | -------------- |
| GPT      | ❌                        | ✅              |
| BERT     | ✅                        | ❌              |
| T5       | Encoder双向，Decoder单向 | ✅              |



------





## **关键差异**







### **GPT**





注意力矩阵是下三角：

```
x x x 0
x x 0 0
x 0 0 0
0 0 0 0
```

未来不可见。



------





### **BERT**





全矩阵：

```
x x x x
x x x x
x x x x
x x x x
```

完全双向。



------





### **T5 Decoder**





和 GPT 一样是因果 mask。



但还会额外：

```
Query → Encoder Keys
```



------





# **三、训练目标的根本差异**





------





## **🔹 GPT**





自回归语言建模：



$\max \sum \log P(x_t|x_{<t})$



简单、统一。



------





## **🔹 BERT**





Masked Language Model：



- 随机 mask 15%
- 预测被 mask token





问题：



训练时可以看到双向，

推理时不能。



这是所谓：



> 预训练目标和下游不一致。



------





## **🔹 T5**





Span Corruption：



- mask 一段
- 输出整个 span





类似序列到序列。



------





# **四、信息流差异**





------





## **GPT**





信息单向流动：

```
左 → 右
```

适合生成。



------





## **BERT**





信息双向流动：

```
左 ↔ 右
```

适合理解。



------





## **T5**





Encoder 双向

Decoder 单向

中间有 Cross-Attention



这是最通用结构。



------





# **五、应用场景对比**





------





## **GPT**





优势：



- 长文本生成
- 对话
- 代码生成
- 多轮推理





原因：



- 完全符合生成过程





------





## **BERT**





优势：



- 分类
- 实体识别
- 情感分析





原因：



- 输出是表示
- 可以取 [CLS]





------





## **T5**





优势：



- 翻译
- 摘要
- QA





因为：



> 所有任务转成 text → text

# **六、为什么 GPT 路线最终胜出？**





核心原因有 5 个。



------





## **1️⃣ 训练目标更自然**





真实语言就是：



$P(x_t | x_{<t})$



GPT 没有预训练-推理 mismatch。



------





## **2️⃣ 可扩展性最好**





Scaling Law 发现：



- 自回归模型扩展效果最好
- 训练稳定





------





## **3️⃣ 推理效率高**





Decoder-only：



- 只用一个模型
- KV cache 复用





Encoder-Decoder：



- 推理成本更高





------





## **4️⃣ 微调更方便**





Instruction tuning：



只需继续语言建模。



------





## **5️⃣ 统一多模态更简单**





Decoder-only 容易接：



- 图像 token
- 音频 token





------





# **七、一个更深入的理解**





可以这样看：

| **模型** | **本质**       |
| -------- | -------------- |
| BERT     | 表征学习器     |
| GPT      | 生成分布建模器 |
| T5       | 条件生成器     |



------





# **八、从信息论角度理解**





BERT 学的是：



$P(x_i | x_{context})$



局部条件概率。



GPT 学的是：



P(x)



完整联合分布。



联合分布更强。



------





# **九、现代趋势**





现在几乎所有大模型：



- GPT 系
- Decoder-only
- 加 instruction tuning





BERT 已逐渐淡出大模型主流。



------





# **十、面试高质量回答**





如果问：



> GPT、BERT、T5 有什么本质区别？



可以说：



> GPT 是 Decoder-only，自回归建模，适合生成任务；BERT 是 Encoder-only，采用双向注意力和 MLM 目标，适合理解任务；T5 是 Encoder-Decoder 结构，将所有任务统一为文本到文本生成。现代大模型多采用 GPT 架构，因为其训练目标与生成过程一致，扩展性更好。



------





# **十一、一个真正深层问题**





为什么：



- BERT 不能直接用于生成？
- GPT 也能做分类？
- T5 理论上最强却没成为主流大模型？







这三个问题问得非常好。

它们其实都在问同一个本质问题：



> **不同概率分解方式，决定了模型“天然适合做什么”。**



我们一个一个讲透，而且讲到“为什么”。



------





# **一、为什么 BERT 不能直接用于生成？**





核心原因只有一句话：



> BERT 不是一个自回归模型。



------





## **1️⃣ 看训练目标**





BERT 训练的是：



$P(x_i \mid x_{\text{左右上下文}})$



它学的是：



- 给你完整句子
- 挖掉一个词
- 预测这个词





它从来没有学过：



$P(x_t \mid x_{<t})$



也就是说：



> 它没学“怎么往后接一句话”。



------





## **2️⃣ 推理时会发生什么？**





假设你想用 BERT 生成句子：

```
The cat sat on the ...
```

BERT：



- 需要完整上下文
- 需要 mask 一个位置
- 才能预测





但生成是：



- 每次只知道前面
- 后面还没生成





BERT 无法在“缺未来上下文”的情况下工作。



------





## **3️⃣ 数学原因**





BERT 没有学联合分布：



$P(x) \neq \prod P(x_t | x_{<t})$



它只学了条件分布。



所以它不是一个生成模型。



------





# **二、那为什么 GPT 也能做分类？**





这点非常关键。



GPT 本质上学的是：



$P(x)$



联合概率分布。



------





## **1️⃣ 分类可以转成生成**





例如：

```
Review: This movie is great.
Sentiment:
```

让模型生成：

```
positive
```

分类变成：



$P(\text{label} \mid \text{input})$



而 GPT 本来就学：



$P(x_{label} \mid x_{input})$



完全自然。



------





## **2️⃣ 这叫做“任务统一化”**





GPT 可以把：



- 分类
- 抽取
- 翻译
- 推理





全部变成：

```
Prompt → Completion
```

这就是大模型成功的根本原因。



------





## **3️⃣ 更深层理解**





联合分布模型天然可以得到条件分布：



$P(y|x) = \frac{P(x,y)}{P(x)}$



但反过来不成立。



所以：



> 生成模型 > 判别模型（表达能力上）



------





# **三、T5 理论上最强，为什么没成为主流？**





这个问题很深。



T5 的理论能力是最强的：



- 双向 Encoder
- 单向 Decoder
- Cross Attention





理论表达能力 > GPT



但现实有 4 个问题。



------





# **1️⃣ 推理效率差**





GPT 推理：



- 只跑 Decoder
- 用 KV cache





T5 推理：



- 先跑完整 Encoder
- 再跑 Decoder
- Cross Attention 计算更复杂





成本更高。



------





# **2️⃣ 参数利用效率低**





T5 参数分成两部分：



- Encoder
- Decoder





生成时：



Encoder 是静态的。



GPT 所有参数都参与生成。



参数利用率更高。



------





# **3️⃣ 扩展性问题**





Scaling law 发现：



Decoder-only 扩展更稳定。



Encoder-Decoder：



- 通信更复杂
- 内存更高
- 并行难度更大





------





# **4️⃣ 工程复杂度**





大模型时代最重要的是：



- 能 scale 到 100B+
- 能高效并行
- 能低成本推理





Decoder-only 在工程上明显更优。



------





# **四、本质总结**





可以用一个更抽象的视角：



------





## **BERT**





学的是：



局部条件概率



$P(x_i|context)$



是一个表征模型。



------





## **GPT**





学的是：



联合分布



$P(x)$



可以退化为任意条件分布。



------





## **T5**





学的是：



条件生成模型



$P(y|x)$



能力强，但工程成本高。



------





# **五、为什么最终 GPT 胜出？**





因为：



> 在大模型时代，生成能力 + 可扩展性 > 结构复杂度。



Decoder-only：



- 更简单
- 更易扩展
- 更易部署
- 更适合 RLHF
- 更适合多模态





------





# **六、一个更哲学的理解**





- BERT 是理解世界
- GPT 是模拟世界
- T5 是条件生成世界





模拟世界（联合分布）能力最强。



------





# **七、面试级回答**





如果被问：



> 为什么 GPT 能做分类，而 BERT 不能做生成？



可以说：



> GPT 是自回归模型，学习联合概率分布，因此可以通过 prompt 将分类任务转化为生成任务；而 BERT 采用双向 MLM 训练目标，并未学习序列联合分布，因此无法进行自回归生成。



如果被问：



> 为什么 T5 没成为主流大模型？



可以说：



> T5 架构表达能力更强，但 Encoder-Decoder 推理成本高、扩展复杂度大，而 Decoder-only 模型在大规模训练和部署上更具工程优势，因此成为主流。



------
