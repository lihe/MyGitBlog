# [Python 中浅拷贝（shallow copy）和深拷贝（deep copy）](https://github.com/lihe/MyGitBlog/issues/18)







# **一、核心知识点**





Python 拷贝分三种：

```
a = b              # 赋值（引用）
copy.copy(a)       # 浅拷贝
copy.deepcopy(a)   # 深拷贝
```



------





# **二、不可变类型的拷贝**





不可变类型包括：



- int
- float
- bool
- str
- tuple（内部元素也必须不可变）





------





## **结论：**





> 对于不可变对象，浅拷贝和深拷贝效果一样。



因为：



- 不可变对象不能被修改
- Python 直接复用对象引用
- 不会真正创建新对象（小整数还可能驻留缓存）





例如：

```
a = 5
b = copy.copy(a)
```

此时：

```
id(a) == id(b)
```

修改：

```
a = 10
```

其实是：



> a 指向了新对象 10



b 仍然指向 5



------





### **面试关键话术**





> 对不可变对象来说，浅拷贝和深拷贝没有区别，本质是引用复用，因为对象本身不可修改。



------





# **三、可变对象的拷贝**





可变对象包括：



- list
- dict
- set
- 自定义对象





------





## **1️⃣ 浅拷贝（Shallow Copy）**





特点：



> 只拷贝第一层对象，内部嵌套对象仍然共享引用。



例子：

```
lst = [1, 2, [3, 4]]
lst2 = copy.copy(lst)
```

结果：



- lst 和 lst2 是不同对象
- 但 lst[2] 和 lst2[2] 是同一个对象





修改：

```
lst[2][0] = 99
```

会影响 lst2。



------





### **本质：**



```
浅拷贝 = 新外壳 + 旧内部引用
```



------





## **2️⃣ 深拷贝（Deep Copy）**





特点：



> 递归拷贝所有层级对象

```
lst2 = copy.deepcopy(lst)
```

结果：



- 外层不同
- 内层也不同





修改：

```
lst[2][0] = 99
```

不会影响 lst2。



------





### **本质：**



```
深拷贝 = 递归复制整棵对象树
```



------





# **四、面试真正考察点**





这题核心不是背定义，而是理解：





## **1️⃣ Python 是“引用语义”**





变量保存的是：



> 对象的引用（内存地址）



不是值本身。



------





## **2️⃣ 为什么浅拷贝会出问题？**





因为：



- 容器内部存的是对象引用
- 浅拷贝只复制引用





------





## **3️⃣ 不可变对象为什么安全？**





因为：



- 任何“修改”都是创建新对象
- 原对象不会改变





------





# **五、总结版答题模板（面试直接说）**





你可以这样回答：



------



这题考察 Python 中浅拷贝和深拷贝的区别。



第一，Python 变量存的是对象引用。



第二，对于不可变类型（int、str、bool），浅拷贝和深拷贝效果一样，因为对象不可修改，本质都是引用复用。



第三，对于可变对象：



- 浅拷贝只复制第一层对象，内部嵌套对象仍共享引用。
- 深拷贝会递归复制所有层级对象。





第四，浅拷贝修改嵌套对象会互相影响，深拷贝不会。



本质区别是：



> 是否递归复制对象结构。



------





# **六、一句话总结**



```
赋值 = 传引用
浅拷贝 = 复制壳，不复制内部
深拷贝 = 整棵对象树都复制
```
