# [大模型训练中的稳定性问题及解决方案](https://github.com/lihe/MyGitBlog/issues/39)





# **一、大模型训练稳定性的本质**





训练过程其实是：



$\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$



稳定性问题本质上只有三类：



1. 梯度太大（爆炸）
2. 梯度太小（消失/下溢）
3. 更新震荡（震荡或发散）





所有问题都可以归结为：



> 数值尺度失衡。



------





# **二、1️⃣ 梯度爆炸（Gradient Explosion）**







## **现象**





- Loss 突然 NaN
- Grad norm 极大
- 参数变为 inf





------





## **为什么会发生？**





Transformer 中梯度来自：



$\nabla L = \prod_i W_i$



多层连乘后：



如果某层放大了梯度：



$\|W_i\| > 1$



整体可能指数增长。



------





## **为什么大模型更容易爆炸？**





因为：



- 层数更多
- 参数更大
- Batch 更大
- 学习率放大





------





## **解决方法为什么有效？**







### **1️⃣ 梯度裁剪**





$g = g \cdot \frac{c}{\|g\|}$



限制梯度最大值。



防止更新过猛。



------





### **2️⃣ AdamW / LAMB**





Adam 的自适应更新：



$\frac{g}{\sqrt{v}}$



自动缩小异常梯度。



------





# **三、2️⃣ 激活值异常（Activation Explosion / Collapse）**







## **现象**





- 某些层输出全 0
- 或极大值





------





## **数学原因**





前向传播：



$y = Wx$



方差传播公式：



$Var(y) = n_{in} Var(W) Var(x)$



如果：



Var(W) 不合理



会导致：



- 方差指数增长
- 或逐层衰减





------





## **为什么 Kaiming 有效？**





设：



$Var(W) = \frac{2}{n_{in}}$



代入：



$Var(y) ≈ Var(x)$



保证方差稳定。



------





## **为什么 LayerNorm 有效？**





它强制：



$\text{mean}=0,\quad \text{var}=1$



防止数值爆炸。



------





# **四、3️⃣ 数值下溢（FP16问题）**







## **原因**





FP16 最小正数：



6e-8



小于这个的梯度 → 0



------





## **解决方法**







### **Gradient Scaling**





利用梯度线性性：



$\nabla (sL) = s \nabla L$



放大 loss → 放大梯度。



------





### **BF16**





指数位更大。



不易下溢。



------





# **五、4️⃣ 权重震荡（Loss Oscillation）**







## **现象**





- Loss 剧烈上下波动
- 不收敛





------





## **原因**





更新步长过大：



$\eta \|g\|$ 太大



导致越过最优点。



------





## **为什么 warmup 有效？**





训练初期：



梯度方向不稳定。



小 LR 可以避免发散。



------





## **为什么减小 LR 有效？**





直接缩小更新步长：



$\theta_{t+1} = \theta_t - \eta g$



------





# **六、5️⃣ 死神经元（Dead Neurons）**







## **原因**





ReLU：



$f(x) = max(0,x)$



如果输入一直 < 0：



输出永远 0。



梯度也为 0。



神经元永久死亡。



------





## **为什么 GeLU / SiLU 更稳定？**





它们是平滑函数：



$GeLU(x) = x \Phi(x)$



即使 x<0 也有梯度。



------





# **七、大模型不稳定的深层原因**





随着模型变大：



1. 梯度更噪声化
2. 更新更敏感
3. 数值范围更极端
4. 层数更深





因此：



> 稳定性问题是规模带来的自然副作用。



------





# **八、真正的稳定训练组合**





工业级配置通常是：



- AdamW
- LR warmup
- Cosine decay
- Grad clip
- Mixed precision + scaling
- LayerNorm everywhere
- Kaiming / Xavier 初始化





------





# **九、一个更高级理解**





稳定性其实是：



$\text{Signal Propagation Stability}$



你需要保证：



- 前向方差稳定
- 反向梯度稳定
- 参数更新稳定





------





# **十、终极理解公式**





如果满足：



$Var(\text{activation}) ≈ 常数$

$Var(\text{gradient}) ≈ 常数$



训练才会稳定。



------





# **十一、面试级总结**





如果问：



> 大模型稳定性问题？



你可以回答：



> 大模型训练中的不稳定性主要来自梯度爆炸、数值下溢和参数震荡，本质是数值尺度失衡。通过合理初始化、LayerNorm、梯度裁剪、混合精度缩放以及学习率调度，可以保证前向和反向的方差稳定，从而实现可扩展训练。



------
