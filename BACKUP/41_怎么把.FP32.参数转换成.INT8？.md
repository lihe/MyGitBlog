# [怎么把 FP32 参数转换成 INT8？](https://github.com/lihe/MyGitBlog/issues/41)

把 **FP32 参数转换成 INT8** 的核心思想其实很简单：



> **用整数去近似表示浮点数，通过“缩放（scale）+ 偏移（zero point）”把浮点数映射到整数范围。**



我一步一步从 **原理 → 数学公式 → 实际例子 → 推理计算 → 量化类型** 帮你彻底理解。



------





# **一、为什么要把 FP32 转成 INT8**





FP32 参数：

```
32 bit = 4 bytes
```

INT8 参数：

```
8 bit = 1 byte
```

好处：

| **优势** | **解释**      |
| -------- | ------------- |
| 模型更小 | 减少 4 倍存储 |
| 计算更快 | INT8 运算更快 |
| 显存更小 | 部署更容易    |

因此：

```
FP32 → INT8
```

叫做 **模型量化（Quantization）**



------





# **二、INT8 的数值范围**





INT8 可以表示：



有符号：



[-128,127]



无符号：



[0,255]



通常使用：

```
-128 ~ 127
```



------





# **三、量化的核心思想**





假设某个 FP32 权重范围是：

```
[-2.5 , 2.5]
```

而 INT8 范围：

```
[-128 , 127]
```

我们需要建立 **映射关系**：

```
浮点数 ↔ 整数
```

这个映射用：

```
scale
zero_point
```



------





# **四、量化公式**





量化（FP32 → INT8）



$q = round(\frac{x}{scale}) + zero\_point$



反量化（INT8 → FP32）



$x = scale (q - zero\_point)$



其中：

| **变量**   | **含义** |
| ---------- | -------- |
| x          | FP32     |
| q          | INT8     |
| scale      | 缩放因子 |
| zero_point | 零点     |



------





# **五、scale 如何计算**





假设：



浮点范围：



$[x_{min}, x_{max}]$



INT8范围：



$[q_{min}, q_{max}]$



scale：



$scale = \frac{x_{max}-x_{min}} {q_{max}-q_{min}}$



------





# **六、zero point 计算**





$zero\_point = q_{min} - \frac{x_{min}}{scale}$



通常取：

```
round
```



------





# **七、完整例子**





假设：



FP32 权重：

```
[-2.5 , 2.5]
```

INT8：

```
[-128 , 127]
```



------





### **第一步：计算 scale**





$scale = \frac{2.5 - (-2.5)} {127 - (-128)}$



$scale = \frac{5}{255}$



$scale ≈ 0.0196$



------





### **第二步：量化**





假设权重：

```
x = 1.0
```

量化：



$q = round(\frac{1.0}{0.0196})$



q ≈ 51



INT8：

```
51
```



------





### **第三步：反量化**





恢复 FP32：



x = 0.0196 × 51



x ≈ 0.9996



非常接近原值。



------





# **八、推理时如何计算**





神经网络计算：



FP32：



$y = Wx$



INT8 量化后：



$y = scale_W scale_x (q_W q_x)$



步骤：

```
INT8 × INT8 → INT32
```

再：

```
INT32 × scale → FP32
```



------





# **九、量化类型**







### **1 权重量化**





只量化：

```
W
```



------





### **2 激活量化**





量化：

```
W + activation
```



------





### **3 Post Training Quantization（PTQ）**





训练后量化。



不需要重新训练。



------





### **4 Quantization Aware Training（QAT）**





训练时模拟量化。



精度更好。



------





# **十、量化粒度**







### **1 Per-tensor**





整个 tensor 一个 scale。



------





### **2 Per-channel**





每个通道一个 scale。



更准确。



例如：

```
Conv kernel
```



------





# **十一、为什么 INT8 计算更快**





CPU / GPU / NPU 都有：

```
INT8 tensor core
```

例如：

```
NVIDIA TensorRT
```

INT8 推理速度：

```
2x ~ 4x
```



------





# **十二、总结一句话**





FP32 → INT8 的核心就是：



> **用 scale 和 zero point 建立浮点数与整数之间的线性映射，从而用整数近似表示浮点参数。**



量化公式：



$q = round(\frac{x}{scale}) + zero\_point$



反量化：



$x = scale (q - zero\_point)$



------
