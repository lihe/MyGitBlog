# [什么是 L1 正则化？什么是 L2 正则化？](https://github.com/lihe/MyGitBlog/issues/27)



# **✅ 一句话速答（面试先说）**





> L1 正则化是在损失函数中加入参数绝对值之和，鼓励参数稀疏；L2 正则化是在损失函数中加入参数平方和，鼓励参数变小但不为零。L1 常用于特征选择，L2 更常用于深度学习模型训练。



------





# **一、什么是正则化？**





在训练中我们最小化：



$L(\theta)$



但模型可能：



- 过拟合
- 参数过大
- 泛化能力差





于是加入正则项：



$L'(\theta) = L(\theta) + \lambda R(\theta)$



其中：



- $\lambda$：正则强度
- $R(\theta)$：正则函数





------





# **二、L1 正则化**





定义：



$R(\theta) = \sum_i |\theta_i|$



新的损失函数：



$L' = L + \lambda \sum_i |\theta_i|$



------





## **特点**





- 会产生稀疏解（很多参数变成 0）
- 等价于 Laplace 先验
- 常用于特征选择





------





## **为什么会变稀疏？**





因为：



- L1 在 0 点不可导
- 梯度恒定
- 会“强行”把小权重压到 0





------





# **三、L2 正则化**





定义：



$R(\theta) = \sum_i \theta_i^2$



新的损失函数：



$L' = L + \lambda \sum_i \theta_i^2$



------





## **特点**





- 权重会变小
- 但很少变成 0
- 等价于 Gaussian 先验
- 又叫 weight decay





------





## **梯度是什么？**





$\frac{\partial}{\partial \theta} \lambda \theta^2 = 2\lambda \theta$



更新变成：



$\theta = \theta - \eta(\nabla L + 2\lambda \theta)$



相当于：



> 每一步都把参数往 0 拉一点



------





# **四、L1 vs L2 对比**



| **对比** | **L1**   | **L2**   |
| -------- | -------- | -------- |
| 正则形式 |          | θ        |
| 是否稀疏 | 是       | 否       |
| 适合     | 特征选择 | 深度学习 |
| 几何形状 | 菱形     | 圆形     |



------





# **五、几何直觉（面试加分）**





最小化：



$Loss + \lambda R(\theta)$



在二维空间：



- L1 约束是“菱形”
- L2 约束是“圆形”





菱形更容易在坐标轴上取得最优解 → 稀疏



------





# **六、在深度学习中的使用**





在大模型中：



- 几乎都用 **L2**
- 实际用的是 **AdamW 的 weight decay**
- 很少用 L1（因为会破坏表示能力）





------





# **七、为什么大模型不用 L1？**





因为：



- L1 会破坏连续表示空间
- 深度网络需要 dense 表示
- 稀疏结构更适合 MoE，而不是 L1





------





# **八、面试官级总结（建议背）**





> L1 正则化通过惩罚参数绝对值之和，使模型参数变得稀疏；L2 正则化通过惩罚参数平方和，使参数整体变小但保持连续性。在深度学习中通常使用 L2 正则化（weight decay）来提高模型泛化能力。



------





# **九、一句“非常高级”的总结**





> L1 让参数“消失”，L2 让参数“变小”。
