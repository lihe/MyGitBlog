# [LeetCode 21：合并两个有序链表](https://github.com/lihe/MyGitBlog/issues/48)

这是 **LeetCode 21：合并两个有序链表**，属于链表题里最基础的 **双指针 + 迭代** 模板。



核心思想非常简单：



> **每次从两个链表头中选较小的节点接到新链表后面。**



------





# **一、直观理解**





给定：

```
l1: 1 → 2 → 4
l2: 1 → 3 → 4
```

我们不断比较两个链表当前节点：

| **l1** | **l2** | **选择** |
| ------ | ------ | -------- |
| 1      | 1      | 1        |
| 2      | 1      | 1        |
| 2      | 3      | 2        |
| 4      | 3      | 3        |
| 4      | 4      | 4        |
| None   | 4      | 4        |

结果：

```
1 → 1 → 2 → 3 → 4 → 4
```



------





# **二、核心思路**





使用三个指针：

```
dummy → 结果链表头（哨兵节点）
cur   → 当前尾节点
l1    → 链表1指针
l2    → 链表2指针
```

流程：

```
1 比较 l1 和 l2
2 小的接到 cur 后面
3 移动该链表指针
4 cur 向后移动
```



------





# **三、代码实现（迭代版）**



```python
class Solution:
    def mergeTwoLists(self, l1, l2):
        dummy = ListNode(0)
        cur = dummy

        while l1 and l2:
            if l1.val <= l2.val:
                cur.next = l1
                l1 = l1.next
            else:
                cur.next = l2
                l2 = l2.next
            
            cur = cur.next

        # 把剩余部分接上
        cur.next = l1 if l1 else l2

        return dummy.next
```



------





# **四、代码逐行解释**







## **1 创建哨兵节点**



```
dummy = ListNode(0)
cur = dummy
```

dummy 的作用：

```
方便返回头节点
避免空链表特殊处理
```

结果链表：

```
dummy → ?
```



------





# **2 遍历两个链表**



```
while l1 and l2:
```

只要两个链表都没结束就继续比较。



------





# **3 比较两个节点**



```
if l1.val <= l2.val:
```

如果 l1 小：

```
cur.next = l1
l1 = l1.next
```



------





# **4 cur 向后移动**



```
cur = cur.next
```

链表尾巴向后移动。



------





# **5 接剩余链表**





当某一个链表结束：

```
cur.next = l1 if l1 else l2
```

例如：

```
l1: None
l2: 4 → 5
```

直接接上。



------





# **五、完整执行过程**





初始：

```
l1: 1 → 2 → 4
l2: 1 → 3 → 4
dummy
```

步骤：

```
1 vs 1 → 1
1 vs 3 → 1
2 vs 3 → 2
4 vs 3 → 3
4 vs 4 → 4
```

最后：

```
1 → 1 → 2 → 3 → 4 → 4
```



------





# **六、递归解法（另一种写法）**





也可以递归：

```python
class Solution:
    def mergeTwoLists(self, l1, l2):
        if not l1:
            return l2
        if not l2:
            return l1
        
        if l1.val < l2.val:
            l1.next = self.mergeTwoLists(l1.next, l2)
            return l1
        else:
            l2.next = self.mergeTwoLists(l1, l2.next)
            return l2
```

递归思想：

```
较小节点作为头
剩下部分继续递归
```



------





# **七、复杂度**





设：

```
n = len(l1)
m = len(l2)
```

时间复杂度：

```
O(n + m)
```

空间复杂度：

```
O(1)   (迭代)
O(n+m) (递归栈)
```

# **九、面试回答模板**





你可以这样说：



> 使用双指针，每次比较两个链表当前节点的值，把较小节点接到新链表尾部，然后移动对应指针。当其中一个链表结束后，把剩余链表直接接到结果链表后面即可。时间复杂度 O(n+m)。
