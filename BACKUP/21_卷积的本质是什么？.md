# [卷积的本质是什么？](https://github.com/lihe/MyGitBlog/issues/21)






这题经常被问。



------





## **1️⃣ 信号处理角度**





卷积是：



> 滤波操作



数学表达：



$y(t) = \sum x(\tau) h(t-\tau)$



在信号系统中：



- x 是输入
- h 是系统响应
- y 是输出





------





## **2️⃣ 深度学习中的卷积**





卷积核本质是：



> 可学习的滤波器



计算方式：



$Output = Kernel \cdot Patch$



也就是：



局部区域点乘求和。



------





## **3️⃣ 为什么卷积能提取特征？**





关键在三个点：



------





### **(1) 局部连接**





每个卷积核只关注局部区域。



图像特征本来就是局部的：



- 边缘
- 角点
- 纹理





------





### **(2) 权重共享**





同一个卷积核在整张图滑动。



意味着：



> 同一种特征在不同位置都能被识别。



比如：



- 竖直边缘
- 横向边缘





------





### **(3) 可学习滤波器**





传统方法：



人工设计滤波器：



- Sobel（边缘）
- HOG
- Gabor





CNN：



> 卷积核通过反向传播自动学出来。



所以 CNN 本质是：



> 自动学习滤波器。



------





# **三、卷积为什么有效？**





从数学上看：



卷积 = 模板匹配



如果图像中有某种结构和卷积核匹配：



点积结果就大。



例如：



边缘检测卷积核：

```
[-1 -1 -1
  0  0  0
  1  1  1]
```

遇到横向边缘时：



输出值很大。



所以：



> 卷积核就是“特征检测器”。



------





# **四、卷积层做了什么？**





卷积层学到：



第一层：



- 边缘
- 颜色块





中间层：



- 纹理
- 局部形状





深层：



- 物体部分
- 高级语义





这叫：



> 分层特征学习



------





# **五、传统特征 vs CNN 特征**



| **传统方法** | **CNN**      |
| ------------ | ------------ |
| 人工设计特征 | 自动学习特征 |
| 可解释       | 黑盒         |
| 固定模板     | 可训练模板   |



------





# **六、面试标准回答（可直接说）**






卷积的本质是一种局部加权求和的滤波操作。在 CNN 中，卷积核是可学习的滤波器，通过在图像上滑动进行局部特征提取。由于权重共享和局部连接，卷积可以有效捕获空间局部结构，并且具备平移等变性。



------





# **七、最核心理解**





卷积：



> 在做“局部模式匹配”



Pooling：



> 在做“信息压缩 + 鲁棒增强”



------





# **八、加深理解的一个关键概念**





卷积是“平移等变”的：



输入平移 → 输出也平移



Pooling 带来“平移不变性”。
